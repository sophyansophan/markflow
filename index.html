                  💻 Cara Instal di MacBook (macOS)
                

                
    
                  
  1. Buka URL GitHub Pages Anda di Google Chrome, Microsoft Edge, atau Safari (macOS Sonoma+).
    2. 
                  
  2. Di Chrome/Edge: klik ikon Instal MarkFlow di sisi kanan address bar atau klik tombol Instal Aplikasi di pojok kiri bawah.
    3. 
                  
  3. Di Safari MacBook: klik menu File → Add to Dock (Tambahkan ke Dock).
    4. 
                  
  4. Aplikasi akan tampil di Dock & Launchpad MacBook layaknya aplikasi native App Store, dan mampu membuka file .md langsung dari Finder.
    5. 
                

              


              

                

                  📱 Cara Instal di HP (iPhone & Android)
                

                
    
                  
  1. Android (Chrome): Ketuk tombol Instal Aplikasi atau buka menu titik tiga ⋮ lalu pilih Instal aplikasi / Tambahkan ke Layar Utama.
    2. 
                  
  2. iPhone / iPad (Safari): Ketuk tombol Bagikan (Share) di bagian bawah layar, lalu pilih Tambah ke Layar Utama (Add to Home Screen).
    3. 
                  
  3. Setiap kali Anda mengedit index.html di GitHub, aplikasi yang sudah terinstal di HP & MacBook akan otomatis mengunduh kodingan terbaru saat terkoneksi internet.
    4.
